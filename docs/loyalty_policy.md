# Synthetic Loyalty Policy

## Earning
Members earn two base points for every Australian dollar spent with an eligible partner.

## Redemption
A member can redeem points only when the available balance is greater than or equal to the requested redemption amount.

## Expiry
Points expire after 18 months without eligible account activity. This is a synthetic rule created only for this demonstration.

## Adjustment
Manual adjustments require an adjustment reason and an audit reference.
